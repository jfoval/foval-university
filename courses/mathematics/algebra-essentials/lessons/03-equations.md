An **equation** says two expressions are equal. Solving it means finding the value of the variable that makes that true.

## The one rule

> Whatever you do to one side, do to the other.

Think of a balance scale. If both pans are level, adding 3 to both keeps them level. Doubling both keeps them level. Your goal is to get the variable alone on one side.

## One-step

`x + 7 = 12` → subtract 7 from both sides → `x = 5`

`4x = 20` → divide both sides by 4 → `x = 5`

`x/3 = 6` → multiply both sides by 3 → `x = 18`

## Two-step: undo in reverse order

`3x + 4 = 19`

The expression was built by multiplying by 3, then adding 4. Undo in reverse: subtract 4, then divide by 3.

`3x = 15`, so `x = 5`

## Variables on both sides

`5x − 2 = 2x + 10`

Subtract 2x from both sides: `3x − 2 = 10`

Add 2: `3x = 12`, so `x = 4`

## With brackets

`2(x + 3) = 4x − 2`

Expand first: `2x + 6 = 4x − 2`

Subtract 2x: `6 = 2x − 2`. Add 2: `8 = 2x`. So `x = 4`.

## Always check

Substitute back into the original. For the last one: left side 2(4 + 3) = 14, right side 4(4) − 2 = 14. ✓

## Word problems

"A taxi charges $3 plus $2 per mile. A ride cost $17. How far was it?"

Let m be miles. `3 + 2m = 17` → `2m = 14` → `m = 7`. Seven miles.

The steps for any word problem: name the unknown, write the equation the story describes, solve, check the answer makes sense in the story.
